##Task 3 Portfolio
For my hypothetical software project, I would use the incremental process model to develop a single-player horror game as a solo game developer. This process would allow me to develop the game in smaller stages rather than trying to complete the entire project all at once. I would begin with a small basic playable version of the game with player movement and a small environment. Further increments would add enemy ai, inventory, additional environments, etc. After each increment I could test the game and make changes based on results. This way is particularly useful in game design as some design decisions may not work out exactly as intended and not obviously so until in gameplay. As a solo developer, incremental development would make the project easier to manage as I could focus on a set feature one at a time. The risk this involves however is that if not careful my designs may become inconsistent if i am constantly changing things and not planned carefully.

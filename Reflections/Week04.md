## Task 2 6 User stories for student timetable portal
1. As a student, I want to see my weekly timetable, so that I know when my class is on.
2. As a student, I want to see what classroom my class is at, so I know where I have to go when my class is on.
3. As a student, I want to who is my lecturer, so I know who is teaching in this class.
4. As a student, I want to recieve notifications when a class is cancelled or rescheduled, so that I know that I don't need to go to class at that time.
5. As a Lecturer, I want to be capable of marking a class as rescheduled or canceled, so that that I know that a class has been notified.
6. As a adminsitrator, I want to see what timetable slots are over capacity, so that I know not to schedule more classes at that time slot.
## Task 2 Acceptance Criteria
User Story: As a Lecturer, I want to be capable of marking a class as rescheduled or canceled, so that that I know that a class has been notified.\
Acceptance Criteria: 1. the lecturer can mark a scheduled class as rescheduled or cancelled\
2. When rescheduling a class, the lecturer can enter a new date, time and location\
3. When a class is canceled or rescheduled, the updated status and details are displayed on the student timetable.\
4. affected students are notified of the cancellation or rescheduling.\

User Story: As a adminsitrator, I want to see what timetable slots are over capacity, so that I know not to schedule more classes at that time slot.\
Acceptance Criteria: 1. The system identifies the time slots that classes exceed room availability\
2. The administrator can view a list of overcapacity slots and their details\
3. Overcapacity slots are highlighted so they can be seen easily\
4. The system warns the administrator if they attempt to schedule another class in one of these time slots.

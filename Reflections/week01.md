Software is the set of instructions that tells a computer or other device what to do. We use software every day in a variety of ways from accessing and learning from the www to playing games. An example of a piece of software is the onion browser which allows users to access the web using the tor browser in a privacy respecting manner. Engineering adds the idea of building software carefully, and its not only about writing code but also involves planning, testing, fixing problems, improving performance and maintaining software. Software that fails is ultimately more frustrating and easier to point out that those that works well. Software that is slow or simply broken can cause a huge upset to many people an example of this is the game 1666 AMSTERDAM that released on early access with a huge amount of bugs and problems with glitches in the game that caused an outrage to those that bought and played it.
An example of a software that i used that has succeeded in its use quite well is firefox that allows users to access the world wide web using a variety of search engines, The variety of addons and privacy settings make firefox different than other browsers. An example of a software that fails at its use in certain areas is epic games which is an online game store that allows users to buy and launch games from the launcher the areas that it struggles in is the ui and the layout of the store that can be unresponsive and unintuitive.
